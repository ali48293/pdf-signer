# SignifyPDF

A premium, open-source web application for signing PDF documents locally in your browser. This project is built with React, Vite, and PDF.js, focusing on maximum privacy, security, and a beautiful user experience. 

All processing happens entirely client-side. Your sensitive documents never leave your computer.

## Features
- **Local Processing**: 100% browser-based PDF parsing and signature embedding.
- **Drag & Drop**: Seamlessly upload files via file explorer or drag-and-drop.
- **Custom Signature Pad**: High-performance, trackpad-friendly canvas for smooth signing.
- **Eraser Tool**: Precisely remove parts of your signature before applying.
- **Draggable Signatures**: Place and drag your signatures anywhere on the document.
- **Premium UI**: Sleek, minimalist dark-mode design with glassmorphism effects.

## Running Locally

To run this project on your local machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/ali48293/pdf-signer.git
   cd pdf-signer
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```
